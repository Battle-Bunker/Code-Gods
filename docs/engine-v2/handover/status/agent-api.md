## 5. Obstacles and lessons the docs may not hold
- Steps (built):
  - QuickJS counts interrupts every 10k ticks.
  - Python counts only the agent's own code, so Python step numbers are about 100× smaller. Any cutoff by steps makes
    the languages diverge, so the parity tests run with a 3M budget.
  - The real cost was gcd re-normalisation in `toQ`, not the search.
- Prices (built):
  - A longer Simple raises every seat's summon price and the beginner start (v2-presets median ±5%).
  - Code in the guest helpers is free; put shared arithmetic there.
  - The primer is capped at 10,000 characters and sits at the limit.
- Guest helper names are global: a new helper silently overrides an existing one (`ladder` broke the pair starters).
- Lookahead (seen narrowly, deal and pool):
  - A two-move lookahead dips in under 2% of moves.
  - Another seat moves the line before the follow-up 12 times out of 15.
  - Survival is 71–75% per foreign move.
- Turnover (seen narrowly): only fresh lines kept climbing. A birth every 30 s with 4–6 live lines cut late two-state
  cycles from about 40% to 0–11%. Seats are always income-bound (85–90% of acts skip).
- More cheap reversible moves mean more flipping: the full menu took deal cycles from 14% to 38% (seen narrowly).
- Mirrors were the only late movement on the round-32 deal. Removing them froze the board. Reading the size whatever
  the sign kept 81% of late moves two-state (seen narrowly).
- Tooling: never `git reset` the working tree while background runs read it (it wrecked one sweep). xargs `-L1` joins
  a line that ends in whitespace onto the next one.
