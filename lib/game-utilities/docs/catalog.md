```python
#
# You worship primes hiding at the front of x. Read |x| one more leading digit at a time
# (7, 73, 739, …) and count how many of those prefixes are prime. Utility is (that
# count, at most 8)³ ÷ 8³. Numbers like 73939133, where every prefix is prime, are
# sacred and very rare.
def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True
```

Example draw: You build nests of parentheses. Track depth as "(" opens and ")" closes (a ")" with nothing open is ignored). Utility is (the deepest level at which a ")" closes, at most 16)² ÷ 16², so "((((…))))" sixteen deep is perfect.

```python
# Nest Builder: your utility function. It maps an object to [0, 1].

def utility(x: str) -> float:

    return min(best, 16) ** 2 / 256
```

### Scale Keeper
<a id="scale-keeper"></a>

*string · Wants the ASCII codes of x to weigh an exact amount.*

Example draw: You weigh strings: add up the ASCII codes of every character in x. You want a weight of exactly 4172; utility is 0.98^(distance from 4172). Random 128-character noise weighs about 8100, and every edit anyone makes shifts the scale.

```python
# Scale Keeper: your utility function. It maps an object to [0, 1].
#
# You weigh strings: add up the ASCII codes of every character in x. You want a weight
# of exactly 4172; utility is 0.98^(distance from 4172). Random 128-character noise
# weighs about 8100, and every edit anyone makes shifts the scale.
def utility(x: str) -> float:
    return 0.98 ** abs(sum(map(ord, x)) - 4172)
```
