## Collapse tests (landscape-analysis.md §4)

The reachable sets cannot be enumerated (previous section), so the tests use sampled windows and searches:

- **Test 1, no ramp:** each rule alone, searched from one birth within path budgets 30, 60 and 120 bits. A ramp
  shows as bits that keep growing with each doubling of the budget while the best state's φ rises.
- **Test 2, no cheap optimum:** for 8 three-seat tables per size, from one birth each, a cheap searcher (2,000
  evaluations of F) against a strong one (100,000), both steepest ascent with random kicks, within a path budget
  of W = 60 bits (about ten unit moves). The table fails if the cheap search reaches 95% of the strong one.
- **Test 3, no single answer:** among every state the strong search evaluated, the best 12 distinct ones as a share
  of 12 × the best; again counting states that differ only by a symmetry of the grid (mirrors, quarter turns)
  or the order of the lines as one; and the top three, to read for a shared closed form.
- Test 4 (no convergence in play) is the climbers section; test 5 (disclosure) is a property of the disclosure
  rules, not of the object, and is not re-run here.
